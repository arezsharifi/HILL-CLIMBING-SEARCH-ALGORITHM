# Hill Climbing Algorithm 🏔️

A clean Python implementation of the **Hill Climbing** search algorithm, based on the classic AI textbook pseudocode.

## What is Hill Climbing?
Hill Climbing is a local search algorithm that continuously moves in the direction of increasing value (uphill) to find the peak of a state space. It stops when it reaches a state where no neighbor has a higher value.

## Features
- Simple, readable implementation
- Follows the standard AI pseudocode
- Easy to plug in your own problem
- Includes a demo example
